# Crime Pattern Analysis using Data Mining Techniques

## Objective
This project analyzes crime datasets to identify crime patterns, trends, and clusters using Python data mining techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn (KMeans Clustering)

## Features
- Data preprocessing
- Label encoding
- Crime trend visualization
- Cluster-based crime pattern analysis
- Crime occurrence by hour
- Top crime types identification

## Outputs
- Crime occurrence graphs
- Cluster analysis charts
- Pattern summary reports

## Conclusion
This project helps understand crime behavior patterns and supports data-driven crime analysis using machine learning and visualization techniques.
